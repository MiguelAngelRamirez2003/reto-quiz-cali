# Proyecto: Cultura de Cali

## 1. Descripción del proyecto

Este proyecto tiene como objetivo desarrollar una aplicación de escritorio que permita presentar información relacionada con la cultura de Cali, destacando aspectos importantes de su identidad cultural, tradiciones, historia y expresiones artísticas.

La aplicación busca ofrecer una interfaz sencilla e intuitiva para que los usuarios puedan consultar información de manera organizada.

## 2. Tecnologías utilizadas

- **Lenguaje de programación:** Python.
- **Interfaz gráfica:** Tkinter.
- **Control de versiones:** Git y GitHub.
